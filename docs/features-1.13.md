# Side Island 1.13 使用指南

> 本页的 1.13 是首次公开发布前的内部开发编号，内容随 v1.0.0 提供。当前公开版本、下载与平台状态以 [中文首页](../README.zh-CN.md) / [English](../README.md) 为准；所述原始诊断记录仅保留本机。

本版新增自动场景、组件布局、分应用音量、局域网传输、截图标注、批量文件处理、通知待办和任务动态。工具页仍使用紧凑卡片、同组等宽按钮和窄窗口自动换行。界面语言、亮暗主题沿用设置中的全局选项；你输入的名称、文件路径和通知内容保持原文。

这份指南说明功能和限制；实际测试结论与完整日志以 `artifacts/features-1.13/` 的验证记录为准。历史设置窗口最小化的来源仍未确定，不能用本次功能回归替代来源证据。

## 1. 自动场景规则

打开「工具 → 自动场景」，先创建规则，选择要应用的已有场景布局，点击「添加／更新规则」，最后「保存全部规则」。编辑列表和输入框属于草稿，「取消更改」恢复已保存内容。

可以同时指定程序名、时间段、显示器和电源条件；留空表示不限制。多个条件必须同时满足。例如 `Code.exe`、`09:00–18:00`、交流电，应用「写代码」布局。程序条件是可执行文件名，不是窗口标题；时间使用本机时间和 `HH:mm`，支持跨午夜。

自动规则默认关闭，需要保存并启用后才会生效。优先级较高的匹配规则先执行；条件稳定约 1.2 秒并满足冷却时间后才切换。手动选择场景会暂停自动切换 10 分钟；也可点击暂停 30 分钟或立即恢复。规则引用的场景被删除后不会继续应用该场景。

仅在自动功能启用或规则编辑器可见时读取当前程序名、显示器及电源状态。程序不收集窗口标题、输入内容或全局应用使用历史。「使用最近应用」只填入已观察到的最近外部程序名；没有可用记录时可直接手动输入。

## 2. 组件布局编辑器

打开「工具 → 组件布局」，选择全局布局或某个场景，启用自定义布局，然后编辑组件池。每个布局可保存 2–6 个组件；收起时同时显示两个，其余组件可轮播。

- 拖动预览卡片调整顺序，或使用前移／后移按钮。
- 选中组件后设置小、标准或大尺寸，预览会立即反映尺寸和顺序。
- 轮播间隔为 `0` 时固定前两个；启用轮播可设为 5–60 秒。
- 点击「保存组件布局」才持久保存；取消恢复上次保存的草稿。

尺寸调整发生在现有收起窗口内，不会把灵动岛扩大为六张同时可见的卡片。某个场景没有自己的布局时使用全局布局；明确关闭某个场景的自定义布局会恢复原来的显示方式。已启用的组件布局优先于整块时钟、专注或自动音乐视图。

可分别允许通知、专注完成和任务动态临时占用显示，并调整 0–100 的优先级。默认优先级为通知 90、专注完成 80、任务 70；数值较高者先显示。通知和专注完成显示约 8 秒后恢复，任务可在进行中持续显示，结束约 8 秒后恢复。任务动态还需要在任务页面开启「收起时显示当前任务」。自定义组件布局默认关闭。

## 3. 分应用音量与输出设备

打开「工具 → 应用音量」。先选输出设备，再查看该设备上的音频会话；需要时点击「刷新会话」。播放音乐或视频后，相应会话才可能出现，已结束或没有音频会话的应用不会凭空列出。

拖动某应用的音量后，点击该行「应用」才修改音量；静音按钮立即切换该会话的静音状态。选择设备本身不会切换系统默认输出，只有「设为默认输出」会执行切换。「Windows 声音设置」可打开系统的更完整选项。

本机只有一个可用输出设备时，可以验证会话音量和静音，但无法实际演示耳机与音箱之间的双设备切换。应用若在自身设置中固定了输出设备，系统默认设备切换未必会迁移其既有会话。

## 4. 局域网传文件到手机

打开「工具 → 局域网传输」，选择或拖入文件，选电脑的局域网地址，设定有效时间和可选口令，再点击「开始分享」。手机与电脑连接同一网络，扫码或打开链接后下载。选择 `127.0.0.1` 仅供电脑本机访问，手机应选择局域网地址。

一次最多 20 个文件，每个不超过 20 GB；有效期为 1–120 分钟。它只提供已选择文件的临时 HTTP 下载，不开放目录浏览或上传入口，也不把文件上传到外部服务器。停止分享或到期会使链接失效，并结束当前下载。

口令在手机网页中输入，不写进二维码。HTTP 不提供加密传输，适合你信任的局域网；分享敏感文件时先确认网络和接收对象。Windows 防火墙可能询问是否允许访问专用网络，应用不会自动修改防火墙。手机热点隔离、访客网络或单位网络限制也可能导致无法连接。

## 5. 截图标注与钉屏

区域截图钉屏后，在截图窗口打开标注工具。可选择箭头、矩形、递增序号、文字或马赛克；文字最多 200 个字符。拖动绘制形状，文字和序号点击放置。「拖动」模式保留原来的窗口移动，滚轮调整缩放。

支持撤销最近标注、清空标注、复制合成图片和保存 PNG。导出会把标注合成为图片像素；原始截图在本次钉屏窗口内保留，关闭窗口后不保存可继续编辑的图层。保存到已有文件时会由保存对话框确认覆盖。

马赛克用于导出图片的视觉遮挡；分享前请检查实际导出的图片，且不要把仍可撤销标注的原始截图窗口当成已销毁原始内容。

## 6. 批量文件处理

打开「工具 → 批量文件」，选择或拖入 1–200 个本机普通文件。先生成预览，核对全部结果后，再执行；任何参数改变都会使旧预览失效。文件夹、链接和网络路径不在这版的处理范围内。

重命名模板支持 `{name}` 原文件名和 `{n}` 编号，另可查找替换原名中的文字、设置起始编号与 1–9 位编号宽度。原扩展名会保留；无效名称、重复目标和覆盖冲突会被阻止。预览会校验文件内容，执行及撤销前再次检查并锁定对应文件，文件被其他程序改动时会停止。

「撤销上次重命名」只适用于当前运行内最近一次成功的重命名，退出程序或执行下次重命名后不再保留该记录。外部文件改变或名称被占用时，撤销也可能被拒绝；请先检查提示。

图片批量处理支持 JPG／PNG，最大 64 MB、2400 万像素。选择输出文件夹、格式、尺寸上限及 JPG 质量，然后预览并执行。缩放保持比例，只缩小、不放大；输出为新的不重名文件，原图不被覆盖。取消会保留已经完成的新文件。处理进度会同步显示在任务动态中。

## 7. 通知转待办、固定、提醒与项目归档

右键消息页中的通知卡片，可转成通知待办、固定，或设置 15 分钟／1 小时后提醒。待办可在「便笺」工具内的「通知待办」区域查看，支持搜索、标记完成／恢复、固定及设置项目名称。

待办单独保存在本机，最多 100 项；清空消息列表不会清空已经保存的待办。项目名称用于归类和搜索。移除待办使用其卡片的右键菜单。

提醒依赖灵动岛运行，不会创建独立的 Windows 计划任务；重新启动后会检查尚未提醒的到期待办。隐私隐藏模式会隐藏待办正文和项目编辑入口，提醒也使用隐藏内容提示。

## 8. 统一任务动态与脚本接入

打开「工具 → 任务动态」，可查看任务守望、服务就绪、批量处理、文件传输和脚本上报的活动，搜索标题、来源及说明，清除已结束记录。已知进度显示百分比，未知进度显示活动状态，不估算百分比。任务记录只保留本次运行，最多 80 项；从列表移除记录不会停止外部进程。

「收起时显示当前任务」默认关闭，开启后允许收起卡片显示任务；如使用自定义组件布局，还需允许任务临时显示。通知或专注完成与任务竞争时遵守组件布局的优先级。

本地脚本接入默认关闭。需要时输入端口（`0` 为自动选择），点击「开启本地接入」，然后复制地址、访问令牌和请求示例。接口仅监听 `127.0.0.1`，只接受带 Bearer 令牌的 `POST /api/tasks`，不执行命令、不提供文件访问或远程管理。

请求示例（请使用页面显示的端口与令牌）：

```powershell
$headers = @{ Authorization = 'Bearer <页面中的访问令牌>' }
$body = @{ id='build'; title='项目构建'; state='running'; progress=25; message='正在编译' } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:<端口>/api/tasks' -Headers $headers -ContentType 'application/json; charset=utf-8' -Body $body
```

同一个 `id` 更新同一任务。`state` 支持 `queued`、`running`、`completed`、`failed`、`cancelled`；`progress` 可省略，提供时为 0–100。结束后再用同一 `id` 上报结束状态。请求正文最多 16 KiB，缓慢或无效请求会被关闭。停止接入后旧令牌失效，下次启动生成新令牌，令牌只保留在内存中。

## 数据、验证与清理记录

自动场景规则、组件布局、通知待办和任务显示偏好保存在现有本机数据目录；任务动态记录及脚本访问令牌仅保留本次运行。不要把访问令牌写进公开代码库或截图。

本版的新增／完整回归、DPI 布局检查及修复记录存放在 `artifacts/features-1.13/`。清理前的路径、体积与引用关系见该目录的 `cleanup-plan.json` 和 `cleanup-review.md`。历史真实原生崩溃、尚未解决的最小化来源追踪及本轮首个失败记录必须保留；大体积原始证据只有在 ZIP 内容逐项 SHA256 校验后才可按已审核计划归档。
