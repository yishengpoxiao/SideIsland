# Side Island · 桌面侧边工具箱

一个可停靠在屏幕上、下、左、右四边的 Windows 灵动岛：收起时查看自定义状态组件或正在播放的音乐，展开后使用媒体、计时、待办、闹钟、日期时区、文件校验、密码生成等 **38 个工具模块**。使用 **C# + WPF / .NET Framework 4.8**，无需 Python、Node.js 或 Electron 运行时。当前通知版：**1.13.0.0**。

1.13 加入自动场景规则、分应用音量、局域网扫码传文件、截图标注、统一任务动态、通知待办、批量处理和组件布局编辑。继续使用紧凑卡片、等宽分组按钮与中英文即时切换。功能说明见 [1.13 使用说明](features-1.13.md)，历史修复见 [1.12 记录](changelog-1.12.md)。诊断和回归原始记录保存在 `artifacts/`。

Apple Silicon Mac 与 Ubuntu 的独立移植预览位于 [cross-platform](../cross-platform/README.md)，Mac 默认优先贴合真实刘海。跨平台窗口、通知来源、截图钉屏和批量文件／图片工具已有独立实现与回归入口；当前主机的构建及无头测试不替代目标设备实测，也不表示 38 项 Windows 功能已全部等价迁移。原 Windows 安装和发行包保持独立。

## 开始使用

便携模式双击 `dist/CodexIsland.exe`（发布包根目录中的 `CodexIsland.exe`），默认出现在主显示器右侧。要接收微信、QQ 等系统通知，请按下文安装通知版；已安装后可运行 `启动通知版.cmd`，或从开始菜单的 **Side Island** 打开。

- **展开与收起**：单击收起的岛、右上角 `−`、Esc 及全局快捷键均立即响应，并以约 220 毫秒动画过渡。默认鼠标首次悬停约 **650 毫秒**才展开。在设置中可将“悬停等待时间（毫秒）”改为 **100—5000 毫秒（0.1—5 秒）**，或关闭“悬停时自动展开”，此时鼠标经过、停留或重新进入收起中的岛都不会自动展开，点击星标或空白处仍立即展开。保存设置后立即生效并在重启后保留，关闭开关不会丢失原时长。按下鼠标会取消等待，拖动期间保持收起。移开约 180 毫秒后收起；开启悬停展开时，自动收起中重新移入会从当前轮廓接续展开。点击 `◇` 固定展开；`−` 或 Esc 同时取消固定。下拉菜单、右键菜单、拖拽及对话框操作期间不会自动收起。输入框仍在接收键盘输入时保持展开，切换到其他应用后可自动收起；Esc 仍可直接收起。显式收起后不会在鼠标原地停留时立即弹回。
- **三页导航**：**消息**汇集通知，**状态**显示 Codex 额度与 CPU、内存、电源，**工具**进入 38 个工具模块。点击当前工具名旁的“切换工具”展开菜单，可搜索中英文名称、英文标识或用途关键词（如“错误”“全屏”“3000”），按 Enter 打开首个匹配；选中后菜单自动收起。窗口内按 `Ctrl + K` 可直接打开工具搜索。
- **切换恢复**：右击没有菜单的窗口边缘不会阻止后续悬停与自动收起；额度刷新和展开页布局更新会保留已经排队的鼠标移出收起动作。
- **动画过渡**：点击和悬停采用一致的缓起缓停过渡，轮廓和文字交接同步，文字保持正常比例；快速反向切换从当前轮廓接续，按下鼠标不会先跳到终点。后台额度、通知同步保留正在进行的过渡；隐私开关、屏蔽或清空消息会立即移除旧消息画面。系统关闭窗口动画时直接切换。
- **消息列表性能**：只排版可见范围内的通知，单条更新会复用其余卡片；保留最多 50 条历史、滚动位置、筛选与隐私功能，降低消息较多时展开窗口的停顿。
- **常用工具**：右键工具按钮固定或移除，也可在切换菜单点击“固定当前工具”，最多 6 个。固定入口显示在工具页顶部；隐藏的模块不会显示入口。正常退出时记住最后使用的工具，下次进入工具页恢复。
- **自由拖动与四边吸附**：按住收起后的整个岛身，或展开后的标题，向任意方向拖动，也可拖到另一块显示器。超过拖动阈值后立即切为收起形态跟随指针，展开或收起动画中开始拖动也一样；仅按下或轻微晃动保留原点击行为。拖动会取消固定展开，松手保持收起，并按设置吸附到最近的上／下／左／右边缘。拖动过程中不会被悬停或通知打断。若希望停在屏幕中间，在设置中关闭“松手后自动吸附最近的屏幕边缘”，或右键选择“自由摆放（关闭吸附）”。
- **横竖布局与展开方向**：停靠上／下方时收起为横条，停靠左／右侧时收起为竖条；展开面板朝屏幕内部打开，收起后回到原停靠位置。位置、显示器和方向自动保存。
- **文字反转**：右键“收起文字方向”或设置中的同名选项，可选择自动正向、旋转 180°、左右镜像。作用于收起状态的数字、周期标签、时钟和文字，展开内容保持正常阅读方向。
- **展开大小**：拖动展开窗口的四条边或四个角调整宽高，拉伸区域保持透明，不显示高亮和四角图标；悬停时仅改变鼠标指针。贴边时向屏幕内侧拖动可放大，例如停靠右侧抓左下角。切页、收起再展开及重启均保留大小；右键“恢复默认展开大小”可重置。尺寸限于当前屏幕工作区，通常为 360—900 DIP 宽、360—1100 DIP 高；小屏幕会自动缩小到可见范围。
- **语言与主题**：展开后的标题右侧提供 **EN／中** 和 **☼／☾** 切换按钮，立即切换中英文、亮色／暗色，也可在设置中选择。输入内容、通知正文、文件名、图片和二维码像素保持原样；选择会自动保存。
- **收起组件与模块**：在“工具 → 模块与外观设置”中选择“双组件自定义”，分别设置两个位置，可选 **Codex 短期额度、Codex 每周额度、CPU、内存、电池、时钟、专注计时、唤醒剩余时间、未读通知数、正在播放、端口占用、任务动态**，允许重复或任意组合，例如“Codex 每周额度 + CPU／音乐”。也可选择整块时钟、专注或音乐模式。可调整 **60%—100% 不透明度**、是否置顶，以及显示哪些工具模块。
- **收起时快捷操作**：单击专注组件即可开始、暂停或继续当前计时；单击唤醒组件可开启／停止临时保持唤醒，初始时长 30 分钟，本次运行内会记住最后选择的时长。两者保持收起，右键组件可进入对应设置。点击额度、系统状态、时钟或通知组件可打开对应详情。悬停组件不会抢先展开；开启悬停展开时，悬停星标或岛身空白处可展开；关闭后点击即可。按住组件拖动或取消手势不会启动功能。旧版整块专注模式也支持点击。
- **后台运行**：收起、切换页面或通过托盘暂时隐藏窗口，Codex 刷新、已开始的计时和提醒仍继续。隐藏“专注计时”或“提醒闹钟”模块不会停止任务；退出程序会结束当前专注计时。闹钟列表会保存，下次启动时补发过期提醒一次。
- **退出与启动**：右键或托盘菜单选择“退出”。设置中可开启“登录 Windows 时启动”，默认关闭；移动安装位置后需重新设置启动项。
- **启动与找回窗口**：通知权限检查与消息读取在后台执行，首屏不等待 Windows 通知服务。再次打开程序会唤醒现有窗口；启动尚未完成时显示请求会排队。托盘“显示灵动岛”、重复启动及用于展开／收起的全局快捷键均会恢复最小化窗口并校正屏幕外位置，保留原来的置顶偏好。演示和预览进程不会占用正式程序的单实例锁。

默认快捷键：

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl + Alt + Space` | 显示灵动岛并切换展开／收起 |
| `Ctrl + Alt + P` | 切换消息隐私模式 |
| `Ctrl + K` | 灵动岛内展开工具搜索；输入后按 Enter 打开匹配工具 |
| `Esc` | 灵动岛内取消固定并收起 |

若全局快捷键被其他程序占用，工具页会显示提示，仍可通过鼠标和托盘操作。

在“工具 → 桌面交互”中可修改全局展开、隐私、搜索、截图快捷键；新快捷键注册失败时会尝试恢复原设置并显示冲突。搜索、截图全局快捷键初始为空；`Ctrl + K`、`Esc` 为窗口内快捷键。

## 桌面交互与场景

- **全屏自动避让**：在“桌面交互”中选择关闭、自动隐藏或贴边细条。默认关闭。仅检测灵动岛所在显示器的前台全屏窗口；退出全屏后恢复显示并保留位置。细条可点击找回，主动找回后不会立即再次隐藏。窗口最大化不等同于全屏。
- **手势自定义**：分别选择收起状态的单击、中键和滚轮动作。默认单击执行组件动作，中键无操作；在收起音乐卡片上滚轮每格调节 2% 系统输出音量。可改为展开、搜索、截图、专注、媒体控制、输出／麦克风静音、快捷启动或禁用。鼠标松手才执行点击，移动超过阈值则取消，展开标题拖动保持原规则。
- **多显示器位置**：默认分别记住每个显示器的停靠边与相对位置（含自由摆放）。在“桌面交互”选择显示器并点击“移动到所选显示器”可恢复该屏已存位置；直接跨屏拖动按松手位置重新保存。屏幕断开时回到主显示器，同次运行中重新连接且未主动切换屏幕时恢复原位置。
- **场景布局**：提供“写代码”（Codex 每周额度＋端口）、“听音乐”（封面与歌词）、“专注”（倒计时＋静默预览）三个内置布局，可保存最多 20 个自定义布局、恢复上个布局。布局包含收起模式、双组件、常用工具、默认工具与静默预览，不改变悬停、语言和主题设置。专注布局不会自行开始计时，点击专注组件开始。工作场景编辑器可关联布局，点击“启动场景”时先应用布局再打开资源。
- **端口组件**：双组件可选“端口占用”，按端口工具当前查询列表每 3 秒更新占用数量，点击查看详情；部分协议不可读时显示问号。
- **功能搜索**：`Ctrl + K` 支持按用途查找，例如“报错”“复制”“全屏”“microphone”“3000”；Enter 打开首个匹配工具。
- **启动诊断**：在“启动诊断”中查看本次与上次启动阶段、首屏耗时、屏幕是否存在、全屏避让状态、悬停设置、设置文件是否为有效 JSON，以及异常类型／错误码。可手动另存报告；不会收集消息正文、剪贴板、歌词或账户凭据。

## 剪贴板历史与日志追踪

**剪贴板历史**每次启动默认暂停，点击“开始记录”后只保存之后复制的文字和图片。支持搜索、收藏、重新复制、清空未收藏记录及按来源进程名排除应用。最近 50 项仅保留在内存；最多 20 项收藏和排除列表保存在本机。单条文字最多 65536 字符，图片最长边 1600 像素、单条 1 MB，总计 8 MB。Windows 标记为不允许历史记录的内容会略过；来源不可识别时可暂停记录。读取在独立后台 STA 线程处理，等待超时不会阻塞灵动岛。

**日志追踪**选择日志文件、填写可选关键词并开始，后台每秒读取新增内容，支持搜索、暂停、自动滚动和清空显示。初次只读取最后 64 KB，最多显示 1000 行；支持 UTF-8 和带 BOM 的 UTF-16／32，并处理日志截断与轮转。关键词提醒每 10 秒最多一次，不修改日志文件。退出后停止，不会自动恢复监测。

## 通知优先级与合并

“消息 → 管理应用”可将应用设为普通或重要。普通应用只增加未读数量，重要应用优先排列并按预览开关提醒；静默预览、隐私和应用禁用设置仍然生效。默认将同一应用 60 秒内标题与正文完全一致的通知合并，卡片显示重复次数；未读仍按真实通知条数累计。可关闭合并。通知正文仅保留在本次运行内存，优先级与禁用设置保存在本机。

## 工具箱

### 截图提字 OCR

在“截图提字”中框选屏幕，或选择 JPG／PNG、显式读取剪贴板图片，在本机识别文字。可选择 Windows 已安装的 OCR 语言；没有可用模型时显示提示。识别结果可编辑、复制、送入“文字对照”，不会上传图片。框选时暂时隐藏灵动岛，完成或取消均恢复；识别可取消。图片最长边缩至 4096 像素，结果最多 120000 字符。

### 搜索直接执行

按 `Ctrl + K` 输入命令，确认提示后按 Enter 执行。保留普通名称和用途搜索；命令仅调用已提供的功能，不执行任意终端命令。

| 输入示例 | 操作 |
| --- | --- |
| `专注 45 分钟` / `focus 45 min` | 保存时长并重新开始专注 |
| `查端口 3000、8080` / `port 8080` | 进入端口模块查询 |
| `生成二维码 https://example.com` / `qr https://example.com` | 将内容送入二维码模块 |
| `复制模板 周报` / `template Weekly` | 复制对应已保存模板 |
| `启动场景 写代码` / `launch scene Coding` | 按唯一名称启动已保存工作场景 |
| `切换布局 听音乐` / `layout music` | 应用对应场景布局 |

### 智能拖放

拖到岛身后选择操作：图片可压缩／调整、钉屏、OCR、校验或收纳；单个普通文件可校验或收纳，多个文件可一起收纳；文本可进入文字对照或生成二维码。最多 100 个文件、120000 字符文本，超限不会截断。菜单在拖放结束后打开，可取消；输入框、文件收纳与文件校验面板保留原有拖放方式。

### 服务就绪提醒

选择 TCP 主机与端口、HTTP／HTTPS 地址，或文件完整路径，手动开始等待。TCP 接受连接、HTTP 返回 2xx、文件大小与修改时间连续稳定后提醒一次。文件稳定时长可设 1—3600 秒，默认 5 秒；最多 20 项，可取消或移除。后台轮询不重叠，连接或文件检查有超时，HTTP 不读取正文、不跟随重定向、不发送 Windows 凭据。退出后停止，不自动恢复任务。

### 常用文本模板

保存、搜索、编辑、删除和复制常用提示词、回复或代码片段。最多 50 个模板，名称 60 字、正文 12000 字、总计 512 KB。支持 `{date}`、`{time}`、`{datetime}`、`{yyyy}`、`{MM}`、`{dd}`、`{HH}`、`{mm}`、`{ss}`，实时预览，未知占位符保持原样；只在明确复制时写入剪贴板，不自动粘贴。草稿未保存时会在退出前保留窗口，避免丢失。

### 设置备份与迁移

导出布局、手势、快捷键、通知规则、音乐偏好，以及自动场景、组件布局和任务显示偏好到单个 JSON 备份。导入前先预览文件清单，再安排下次启动应用，可取消待导入；兼容旧版五文件备份。保留目标电脑原有 Codex 路径和开机启动设置，不导出账户路径、剪贴板、便签、通知待办正文、脚本令牌或模板正文。导入有格式、大小及字段检查；保留一份本地恢复副本，写入失败恢复原始文件。应用数据目录不能作为导出目标，避免覆盖当前配置。

### 本轮交互和后台优化

- **播放器锁定**：在媒体面板刷新播放器列表并指定跟随来源；读取歌曲与发送播放命令使用同一会话。指定播放器未运行时保持等待，不切换去控制浏览器或会议音频。选择自动模式可恢复原行为。
- **临时场景还原**：场景布局提供“专注结束后自动恢复上个布局和通知预览”选项。应用专注布局后生效；手动修改布局或切换其他场景会阻止自动覆盖。开启后退出或意外重启也会还原符合条件的临时布局。
- **拖动撤销**：拖动中按 Esc 恢复原显示器、位置、停靠方向和展开／固定状态；按住 Alt 松手仅临时跳过本次吸附，保留原吸附偏好。
- **全屏按应用规则**：在桌面交互中按进程名配置保持显示、隐藏或细条；没有匹配规则、进程信息不可读时使用全局规则。
- **后台降频**：未显示系统指标时降低采样频率，隐藏窗口进一步降频；系统采样移到后台并避免重叠。专注计时就绪或暂停时停止刷新，后台倒计时按秒更新，展开计时页保留更细刷新；模板预览只在可见时运行。睡眠恢复重新同步当前可见工具，不依赖动画帧计时。

### 端口占用

在工具中搜索“端口”，输入 `3000、8080` 等多个端口，点击“查询 / 刷新”或按 Enter，直接查看 TCP / UDP、IPv4 / IPv6、本地地址、程序名称、PID 和可执行文件路径。勾选“每 3 秒监测”可持续更新。受保护进程显示路径无法读取；部分协议读取失败会明确标注，避免误判为空闲。本功能不结束进程。

### 截图钉屏

点击“框选截图并钉屏”，拖动选择屏幕区域，Esc 取消。框选时灵动岛暂时隐藏，完成或取消后自动恢复。截图悬浮置顶，可拖动图片移动、滚轮或滑块缩放、调整透明度以及关闭；大图在受工作区限制的视口中滚动，工具栏保持可用。最多 8 张，每张最多 3200 万像素，仅保留在内存，退出程序关闭全部钉屏。

### 图片快处理

将一张 JPG / PNG 拖到灵动岛，在菜单选择“压缩或调整图片”；也可以在工具中选择图片。支持按比例或分别设置输出宽高、调整 JPG 质量、PNG / JPG 转换及预览。结果另存为新文件，不允许覆盖源路径；JPG 将透明区域铺为白色，PNG 保留透明。输入最多 64 MB / 2400 万像素。拖到“文件收纳”面板时仍按原方式收纳文件引用。

### 文字对照

左右输入两段文本，停止输入约 350 毫秒后自动按行对照，绿色新增、红色删除、橙色修改。左右结果支持同步滚动。每侧最多 120,000 字符、1,600 行；摘要统计完整文本，预览前 600 行，每行最多显示 2,000 字符。仅在本次运行内存中处理，不执行文本。

### 任务守望

选择尚未生成的目标文件完整路径，或从运行列表选择进程 / 输入 PID，后台每秒检查一次。文件出现或指定进程退出时提醒一次，可取消或移除任务。文件出现不代表写入完成；启动时已经存在的文件、已退出的进程不会补发提醒。进程通过 PID 与启动时间共同识别，避免 PID 复用误判。收起和切页继续监测，退出即取消，任务不跨重启保存。

### 临时保持唤醒

选择 30、60 或 120 分钟，临时阻止 Windows 因空闲自动睡眠，灵动岛收起时显示剩余时间。可随时停止，到期或退出自动释放。允许屏幕按原设置关闭；手动睡眠、合盖及低电量行为仍由 Windows 决定。唤醒任务不会跨重启恢复。

### 二维码传话

输入网址或文本后自动生成单张二维码，支持复制图片与保存 PNG。使用明确标记 UTF-8 的 ECI 编码，支持中文和 emoji；默认 L 纠错达到单张最大 **2,952 个 UTF-8 字节**，约 984 个汉字。可选择 M（2,330）、Q（1,662）或 H（1,272 字节）提高纠错能力。字节数实时显示，超限明确提示，不截断、不分段。密集二维码建议保存原图后放大扫码。内容仅在本机生成，不上传，不自动打开链接。二维码编码器的固定版本与 MIT 许可证见 `THIRD-PARTY-NOTICES.txt`。

### 工作场景启动

新建“写代码”等场景，把项目目录、软件和 http(s) 网页组合在一起，也可勾选复用“快捷启动”中已有的入口。单击场景启动按钮批量打开资源，逐项显示失败情况；程序路径与参数分别填写。最多 20 个场景，每个 30 个资源，保存在本机；保存失败时保留编辑内容并在退出前提示重试。场景不会随程序启动自动执行。

### 媒体与声音

收起时显示圆角封面、歌曲名、歌手、当前歌词、播放状态和进度。默认在检测到播放时自动显示音乐卡片，暂停后保留约 12 秒，再恢复原来的组件；选中的专注组件正在计时时优先显示专注。点击封面播放／暂停，提供上一首／下一首按钮，滚轮每格调节 2% 系统输出音量；点击标题或歌词进入媒体面板。按住超过阈值仍可拖动，拖动取消点击。支持四边停靠、亮暗主题和文字旋转／镜像，封面保持正常方向。

在设置或“音乐与声音”中关闭“播放时自动显示音乐卡片”可保留原来的收起内容；也可把收起主内容设为“正在播放”，或仅把两个自定义组件中的一个选为“正在播放”，与 Codex 7d 额度等组件并排显示。

音乐信息来自 [Windows 系统媒体会话（SMTC）](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmediaproperties)。QQ 音乐、网易云音乐、Apple Music、Cider 等播放器**向 Windows 发布媒体会话信息时**可显示其歌名、歌手和封面；功能取决于播放器的具体版本和设置，未提供的封面不会凭空生成。Cider 官方的 [3.1.0 更新记录](https://github.com/ciderapp/Cider-2/blob/main/changelogs/3.1.0.md)确认改善了 Windows 媒体会话支持。收起和展开面板均提供上一首、播放／暂停、下一首，只启用播放器声明支持的按钮；不支持封面控制时点击进入详情。未提供时长、没有媒体会话或不支持控制时，界面会说明状态。媒体访问不可用时请使用已安装的通知版再试。

Windows 没有统一的歌词字段，歌词支持两种来源：

- **可选在线匹配**：在音乐面板或设置中打开“在线匹配歌词”。此选项默认关闭；打开后向 [LRCLIB](https://lrclib.net/docs) 发送当前歌曲的歌名、歌手、专辑和时长，按曲匹配同步歌词。不发送媒体文件或播放器账户资料；无匹配、网络不可用、纯音乐或缺少必要歌曲信息时继续显示原有音乐信息。在线结果只在内存缓存。
- **本地 LRC**：播放目标歌曲后点击“导入 LRC”，选择带时间戳的歌词。支持 UTF-8、UTF-16、常见中文编码、多时间戳、偏移与双语歌词。导入副本按播放器、歌名、歌手绑定，重启后继续使用；本地歌词优先于在线匹配。每份最大 256 KB、5000 个时间标记，最多保留 64 首。“清除当前歌词”清除当前显示及本地绑定，当前歌曲不立即重新在线获取。

1.12.1 增加歌词状态说明、手动重试和可展开的完整歌词。播放器未提供时长时仍可按歌名与歌手查询；未提供可靠播放进度，或仅返回纯文本歌词时，显示全文供对照，不伪造逐句同步。首次缺少专辑／时长、网络暂时失败后，会在信息补全或退避时间到达后重新匹配；本地 LRC 仍优先。

本机真实兼容性记录：QQ 音乐 22.76、网易云 3.1.41 和 Apple Music 1.1540 的播放／暂停、上下首及封面已经用真实 Windows 媒体会话验证。网易云该版本没有发布可用进度，所以完整歌词可读，逐句同步受限；Apple Music 先按上一首会在本曲进度较大时回到开头。Cider 尚未安装，未宣称实测通过。歌词库未匹配到歌曲或服务返回错误时会说明状态，可重试或导入 LRC。

音乐面板可设置歌词字号 9—16、同步偏移 ±10000 毫秒（正值提前），点击“应用歌词显示”或按 Enter 后保存。歌词按播放器提供的时间轴随播放、暂停、跳转更新。播放器未发布可靠进度时不能保证歌词同步，在线曲库也不保证每首歌都有歌词。

开启自动音乐卡片、选择音乐主内容／组件或打开媒体工具时，媒体信息在后台采样；音频设备与系统详情仍仅在对应工具展开可见时采样。收起不会停止播放器、Codex、通知、专注或闹钟。媒体读取、封面解码和歌词文件处理在后台执行，封面按曲缓存并限制为 256 像素，避免拖慢展开与收起。

声音卡片控制默认输出设备音量和静音。拖动滑块后点击 **应用音量**才会修改音量；麦克风按钮切换 **Windows 默认通信麦克风**的静音状态，其他输入设备需在对应应用中设置。

### 专注计时

- **专注时长可以自定义并保存**：在“专注时长（分钟）”输入 **1—1440 分钟**，点击“保存并重置”或按 Enter；专注预设随之更新，下次启动和收起组件使用已保存的时长。保存会把当前计时重置为就绪，不自动开始。默认专注 25 分，另有休息 5 分、长休 15 分。
- 单击收起的计时组件即可开始、暂停或继续；完成后再点可重新开始。已选择休息或秒表时继续控制该模式，避免覆盖已有计时；组件会显示实际模式。右键计时组件可直接进入时长设置。
- 可暂停、继续和重置；切换预设会重置当前计时。
- **秒表**支持暂停恢复与计次，显示最近 10 次记录。
- 倒计时包含电脑休眠时间，到点提醒一次；暂停期间不扣时间。专注完成次数统计本次运行，不跨退出保存。
- 收起时可切换成专注主视图。完成时发送托盘提醒；静默预览开启后不弹出岛内预览，Windows 自身设置仍会影响托盘提醒的呈现。

### 待办便签

在输入框写下事项，按 Enter 或点“添加”；勾选完成，点 `×` 删除，也可一键清除已完成。最多 **30 项**，每项 **160 字符**。随手记支持 **6000 字符**，停止输入约 0.7 秒后自动保存，也可点“立即保存”。待办状态与便签保存在本机，重启后恢复；界面会显示保存成功或失败。

### 快捷启动

内置文件管理、桌面文件夹、截图、任务管理器，以及 Wi-Fi、蓝牙、显示、声音设置入口。Wi-Fi、蓝牙按钮打开 Windows 对应设置页。

“固定应用／文件夹／网址”可添加最多 **20 个**常用入口。支持现有 `.exe`、`.lnk`、文件夹以及 `http(s)` 网址；可通过选择器添加应用和文件夹。入口列表保存到本地，点击后交给 Windows 打开，`×` 仅移除入口。

### 提醒与闹钟

填写标题，点击 **10／30／60 分钟后**，或输入日期 `yyyy-MM-dd` 与 24 小时时间 `HH:mm`。支持单次和每日重复，最多 **30 条**，可暂停、恢复、删除；已经提醒的事项可选择“10 分钟后再提醒”。提醒列表及触发状态保存在本地，重启后恢复。

**需要灵动岛保持运行才能按时弹出。** 休眠或退出期间错过的提醒会在恢复或下次启动时补发一次，每日提醒推进到下一个未来时刻；多个到期提醒合并呈现。暂停的过期单次提醒恢复时改为 10 分钟后，每日提醒恢复为下次时刻。隐私模式隐藏提醒预览和托盘气泡的内容，静默预览阻止岛内自动展开。点击岛内提醒预览进入提醒模块。

### 文件收纳

在文件收纳页拖入文件／文件夹，或使用选择按钮。最多 **30 项**，可查看类型、大小与可用状态，打开、定位、复制路径、移除或清空引用。支持本机路径，不支持网络盘与 UNC 共享；状态在后台检查，超时后可手动刷新。

**仅保存路径引用**，不复制、移动或删除原文件，也不扫描文件夹内容。文档、图片及音视频白名单类型可交给默认应用打开，其他类型仅支持定位；应用启动请使用“快捷启动”模块。原文件移动后入口可能失效，需重新添加。

### 日期与时区

- **世界时钟**：本地、北京、东京、伦敦、纽约与 UTC，按 Windows 时区规则处理夏令时。只在模块展开可见时刷新。
- **日期间隔**：支持是否计入起始日、仅计周一至周五；结束日期默认计入。可交换起止日期。
- **日期加减**：输入正负天数，可仅按周一至周五推算。工作日计算不包含法定节假日与调休规则。
- **Unix 时间戳**：秒／毫秒与日期时间双向换算，明确选择 UTC 或本地时区，也可填入当前时间。夏令时跳转中不存在或重复的本地时间会提示改用明确的 UTC 时间。

日期输入格式为 `yyyy-MM-dd`；完整时间为 `yyyy-MM-dd HH:mm:ss`，可附加 `.fff` 毫秒。修改输入后更新结果，错误输入会清空旧结果并禁用复制。

### 文件校验

选择或拖入一个文件，点击“开始计算”得到 **SHA-256 / SHA-512**，可粘贴预期校验值比较。计算在后台进行，显示进度并可取消；更换文件或算法会清除旧结果。读取所选文件，不修改、上传或持久保存文件内容。校验值一致表示字节一致，不代表来源可信。

### 随机与密码

- **密码生成**：8—128 位，可选大小写、数字、符号，支持排除易混字符，每种勾选类型至少出现一次。
- **随机整数**：支持完整 32 位整数范围，包含上下限。
- **名单抽签／打乱**：每行一项，最多 500 个非空行，可合并完全一致的重复行，抽取指定数量或打乱全部。一次抽取不重复选中同一行，再次抽取重新使用完整名单。

采用系统加密随机数生成，不自动读取或写入剪贴板。结果只在本次运行内存中；修改参数即清除旧结果，关闭应用后无法找回生成的密码。

### 临时文字收纳

点击 **收纳当前剪贴板**时才读取系统剪贴板，平时不监控剪贴板变化。最多保留 **15 条**、每条 **8000 字符**的文本，重复内容移到最前。每条可复制或移除，也可清空收纳区。只存在本次运行内存中，退出即清空。

### 计算器

输入算式后按 Enter 或点“计算”，支持 `+ - * /`、括号、`^` 幂、`%` 百分数、`sqrt()`、`abs()`、`round()`，以及 `pi`、`e`。`%` 表示除以 100，例如 `250 * 15%` 得到 `37.5`。支持复制结果，所有运算在本地完成。

修改算式或计算失败后会清空旧结果并禁用复制，避免复制到上一次的数值。

### 单位换算

支持 **长度、质量、温度、面积、体积、速度、数据容量、时间、能量、压力** 10 类，选择原单位与目标单位后自动计算，可交换单位、复制结果。支持小数与科学计数法，结果最多显示 15 位有效数字。`KB` 按 1000 字节、`KiB` 按 1024 字节；温度拒绝低于绝对零度的输入。固定单位全部离线换算。

### 文字工具

输入或手动粘贴文字，支持字符／词段／行数统计、大小写转换、去重行、删除空白行、清理首尾空格、**JSON 格式化／压缩、URL 参数编解码、Base64 UTF-8 编解码、SHA-256**，也可生成 GUID。处理后原文保留，可复制结果或将结果作为下一步输入。

每次输入上限为 **65,536 个 UTF-16 文本单元**；统计字符按文本元素计数。JSON 保留原始数字与字符串转义，拒绝重复字段名，避免静默覆盖。URL 按单个参数值处理，`+` 保留为加号。内容只存在本次运行内存，不自动读剪贴板、不上传。

### 屏幕取色

点击 **3 秒后屏幕取色**，把鼠标移到目标位置，倒计时结束后读取指针下的一个像素。可取消，也可直接输入 `#RGB`／`#RRGGBB` 色值；显示 **HEX、RGB、HSL**，支持复制、RGB 反色与黑白文字对比度参考。屏幕取色不连续监控、不保存截图；HDR 或受保护画面的结果可能存在差异。切换到其他工具会取消尚未完成的取色。

### 系统详情

显示物理网卡的合计上传／下载速率、最近 **30 次采样**曲线、连接状态和本机 IPv4，以及当前日期时间、开机时长、运行进程数、系统盘剩余容量。网络数据通常每 2 秒采样；连接状态表示网卡链路状态，不代表已验证互联网可达，也不是带宽测速。CPU、内存和电源摘要仍在“状态”页。隐私模式也会隐藏本机 IP 和网卡名称。

## 消息中心

- **同步与恢复**：首次检查权限和读取均显示后台状态，其他工具仍可使用。同步失败会保留原因，并显示“重新同步通知”；重试期间不会提前显示连接成功，也不会清空原有消息或重置未读状态。完整后台检查与同步有 12 秒期限，通知读取自身有 10 秒期限。超时后，取消和清理在后台进行；旧的系统调用或清理未结束时暂缓新读取，避免不断堆积请求，结束后自动恢复。
- **屏蔽软件**：在任意消息卡片点击“屏蔽此应用”，立即从岛内移除该软件已有消息，并停止显示它的后续通知、未读数和预览。
- **管理与恢复**：消息页下方“管理应用”列出收到过通知的软件，可搜索、只看已禁用并“恢复显示”。开关会在重启后保留；恢复后的首次同步不重播旧通知。只影响灵动岛，不改动 Windows 或软件自己的通知设置。
- **收起时**：显示岛内未读消息数，主内容由外观设置决定。新消息可自动展开 6 秒预览，点击进入消息列表。
- **展开时**：默认打开“消息”页，可按全部、微信、QQ、其他筛选；“状态”页保留额度与系统监控。
- **隐私模式**：设置中开启后同时隐藏发送者、标题和正文，保留应用来源。
- **静默预览**：继续收消息和累计未读，暂不弹出岛内预览；可在设置中开启。它不会修改 Windows 或聊天软件自身的免打扰设置。
- **岛内已读／清空岛内记录**：仅作用于灵动岛，不改变微信/QQ 的已读状态，也不删除 Windows 通知。
- **历史**：仅保留本次运行的内存数据，最多 50 条、24 小时。初次连接已有通知标为岛内已读，不重复弹出历史消息。
- **预览示例**：按钮生成明确标记的虚构消息，验证显示与动画，不表示已经接通真实消息。

**接入边界：只接收应用发往 Windows 通知中心的 Toast。** 微信、QQ 需开启系统通知；部分版本只显示自己的独立弹窗，或在免打扰/通知隐私设置下不提供正文，这些内容不会被程序凭空补全。不读取聊天数据库，不注入聊天进程，不发送消息。

## 安装通知版

Windows 的通知监听 API 要求已注册的应用身份、`userNotificationListener` capability，以及用户亲自授予的通知访问权限。**仅双击便携 EXE 不具备通知读取权限**，界面会显示“安装通知版后即可连接”。

1. 关闭正在运行的灵动岛，在完整发布包中运行 `install-notifications.cmd`。
2. 本地开发安装需要 Windows 开发者模式已开启。安装器不会自行开启系统开关或导入证书；若尚未开启，会明确说明并退出。正式分发可使用受信任证书签名的 MSIX，见 `packaging/README.md`。
3. 安装器将程序暂存到 `packaging/app`，注册当前用户的通知版，并通过开始菜单应用身份启动。今后从开始菜单的 **Side Island** 启动通知版；不要直接运行暂存文件夹里的 EXE。
4. 打开岛内“消息中心”，点击 **连接系统通知**，在 Windows 弹窗中亲自选择允许。拒绝后可从 Windows 的隐私通知设置中重新开启。
5. 让微信或 QQ 产生一条真实系统通知，即可验证消息接入。没有授权、没有系统通知或者只有应用自绘弹窗时，不会出现真实消息。

消息正文不写磁盘、不上传服务器。退出时即释放内存历史。取消通知访问权限后停止读取；设置中也能暂停通知汇集。

安装检查和卸载：

```powershell
.\install-notifications.ps1 -CheckOnly
.\install-notifications.ps1 -Unregister
```

保留安装目录，注册后移动文件会使通知版无法启动。更新时先退出灵动岛，再运行安装器更新暂存文件与注册。

## Codex 额度监控

额度监控需要已经安装并登录的 Codex 桌面版或 CLI。即使没有 Codex 账户，也可以使用工具箱的独立工具。

- **额度主视图**：收起时的两个圆环显示各额度周期的剩余百分比；下方是服务返回的周期长度，例如 `5h`。`—` 表示没有数据。
- **后台监控**：默认每 60 秒刷新，即使收起或通过托盘菜单隐藏，也会继续刷新。
- **展开内容**：每个周期的剩余额度、重置倒计时，以及本机 CPU、内存和电源状态。多额度池可用下拉菜单选择。
- **提醒**：额度低于设置的阈值时发送一次托盘提醒，同一重置周期不会反复弹出。Windows 通知设置可能影响提醒显示。
- **退出**：右键或托盘菜单选择“退出”。关闭程序会停止其启动的 Codex 服务。

## Codex 数据来源

通过本机 `codex app-server` 的标准输入/输出连接，完成 `initialize` 握手后只调用 `account/rateLimits/read`。不创建对话，不发起模型推理。协议来自 [OpenAI 官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)。

界面将 `usedPercent` 转换为剩余百分比；优先读取 `rateLimitsByLimitId`，兼容旧版 `rateLimits`。缺失字段显示不可用，接口失败后保留上次成功值并标注“未同步”，不会把旧值当作实时数据。各账户的额度周期可能不同，界面以接口为准。额度属于所连接的 Codex 账户，不是当前对话的 token 数或余额。

程序不会自行读取、显示或复制登录令牌。由本地 Codex 服务使用已有登录状态连接 OpenAI。

程序路径按显式设置、PATH 上的 Codex、Codex 桌面版安装目录查找。支持 npm 安装的 `codex.cmd`/`codex.ps1`，会解析其原生可执行文件，不调用 shell。数据目录按设置、`CODEX_HOME`、常见 Codex 数据目录查找，也可手动指定。若 CLI 和桌面版登录了不同账户，请在设置中指定正确的数据目录。

若显示“未找到 Codex”或连接失败，打开设置，分别选择 `codex.exe` 和已登录的 Codex 数据目录，然后刷新。API key 账户可能不提供 ChatGPT 套餐额度。本版本支持 Windows；使用系统 DPI 感知，跨不同缩放比例显示器切换时清晰度由 Windows 缩放处理。
