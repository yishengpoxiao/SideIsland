# 1.12 界面与稳定性记录

> 本页保留首次公开发布前的内部开发编号，不代表已发布过这些 GitHub 版本。首次公开版本为 v1.0.0；原始诊断记录仅保留本机。

1.12.17 修复在展开收起动画中快速切换中英文或主题时，轮廓直接跳到终点的问题。外观更新立即清除旧内容快照，保留轮廓动画时钟、当前进度和原生窗口；新内容正常显示，动画自然收尾。完整回归与混合切换诊断记录保存在 `artifacts/full-regression-1.12.16/`。

1.12.16 修复切换功能时文字和图标的跳动：页签保持同一字重与文字基线，消息数字仅淡入；工具选择区可以在页面淡入期间独立平滑展开和收起，不再被页面完成回调强制结算高度；窗口操作提示固定在底部。逐帧位置、实际字形与回归记录保存在 `artifacts/function-switch-jitter/`。

1.12.15 将主题画刷改为冻结快照，换肤时替换控件和资源的引用并重绘，避免本机 WPF 原生监听者集合缺陷在颜色更新时调用已销毁对象。中英文、输入选区、动态资源、绑定、自绘颜色和受保护图片颜色保留原有行为。旧布局测试的真实转储、匹配符号、确定性原生算法验证和修复回归记录保存在 `artifacts/native-layout-rootcause/`；诊断工具不改 Windows DLL 或系统崩溃设置。

1.12.14 为收起音乐卡的封面、歌名、歌手和歌词增加约 150 毫秒的淡入，歌词与歌曲信息分别过渡，快速切歌从当前画面接续。紧凑音乐卡原位淡入，避免过渡给大字号额外增加裁切；双组件中的音乐封面和歌名同步淡入，并在留白内轻微位移。播放进度、播放／暂停及能力刷新不重播，控件和窗口大小保持稳定。展开／收起期间切歌会移除含旧歌曲的临时画面并保留原有窗口动画进度；隐藏、拖动、调整大小、切换外观、休眠和关闭及时结束内容动画，休眠同时停止音乐界面计时器。

1.12.13 为连续到达的通知预览增加约 150 毫秒的内容淡入和轻微位移，同次预览期间保持窗口位置与尺寸。新消息立即更新正文、提示与点击目标；快速替换从当前画面接续，相同消息不重播或延长计时；应用更新同一条系统通知时，活动预览也同步刷新，新到达的消息仍优先。首次预览尚在展开时收到下一条消息，会保留原来的几何动画和平滑亮度；清空、屏蔽、隐私设置、隐藏及关闭会清除旧预览内容，避免旧提示或消息引用残留。

1.12.12 为可见通知卡片增加约 180 毫秒的轻滑入、移位和淡出，已读变化平滑淡入；未读计数、消息页签数字及收起未读组件采用约 150 毫秒的轻过渡。消息数据立即更新，重复后台刷新不重播，快速操作从当前画面接续；浏览旧消息时尽量保留阅读位置。清空、屏蔽、隐私与禁用通知会立即移除旧内容，仅安全的新状态参与过渡；切页、收起、拖拽和关闭及时清理动画。

1.12.11 将平滑过渡扩展到设置页已有的折叠分组和通知筛选：设置内容高度、透明度与箭头同步变化，快速反向操作从当前高度接续；通知只淡入最新筛选结果，筛选按钮、消息区域和底部操作保持稳定。重复点击当前筛选及后台同步不重播动画，清空、屏蔽、隐私切换与退出页面及时清理过渡；系统关闭窗口动画时立即切换。

1.12.10 为工具选择区增加约 160 毫秒的高度、内容和箭头同步过渡，选中工具后平滑收起并回到正文顶部；快速反向操作从当前高度接续。修复右上角四个按钮切页、切工具时跳动：标题与页签独立于正文滚动，按钮顶部对齐，并为正文、工具目录和应用通知管理预留稳定的滚动条宽度。工具标题保持单行高度，长名称提供完整提示；切换主页面重置正文滚动位置，避免沿用上一页的长页面偏移。

1.12.9 将约 150 毫秒的轻淡入延伸到工具页内部：只过渡当前工具内容，标题、选择器和窗口位置保持稳定。快速切换以最后选择为准；重复选择当前工具或后台刷新不重播动画，也不会无故滚回顶部。进入工具页与内部工具切换相互协调，避免叠加变暗；收起、拖拽、调整大小和隐私变更会及时结束过渡。

1.12.8 为消息／状态／工具切页增加约 150 毫秒的轻淡入，同次展开期间保持窗口尺寸，避免默认高度跳变；快速切换与后台刷新不会闪回旧页。统一其余应用弹窗与悬浮工具：快捷入口／场景资源编辑器使用分组卡片、正文滚动和固定等宽操作；消息提示改为紧凑圆角卡片，长说明可滚动。修复文字提示首次打开的模板错误，长文本自动换行并限制在显示器工作区内；保留自定义提示内容与隐私保护。截图钉屏改为双列完整缩放／透明度控件，区域截图提示按实测尺寸避让边缘。文件夹选择器绑定所属窗口，系统文件选择器补充中英文标题。

1.12.7 将收起组件、音乐卡、通知预览和右键菜单统一为紧凑 iOS 风格：一致的字体层次、圆角和分组间距，修正组件标签贴底与音乐文本半行裁切；专注主值只显示时间。预览来源、通知类型和点击提示独立对齐，标题与正文支持两整行，隐私占位与完整原文提示保留。右键菜单统一图标／勾选／快捷键／子菜单列，长中英文自动换行，菜单限制在当前显示器工作区内并支持滚动；托盘菜单同步明暗配色与紧凑间距。

1.12.6 统一设置、通知和应用通知管理窗口的紧凑排版：按钮等宽等高、6px 分组间距，卡片留白收紧；设置和应用管理支持 320×360 起的可调整窗口，正文滚动、底部操作常驻。成组字段与模块随宽度变为一／两列，下拉选项完整换行；修正小窗英文未读页签、微信筛选翻译和主窗口图标对齐，保留路径与消息原文及隐私提示保护。

1.12.5 统一 32 个工具页的紧凑排版：同组按钮等宽等高、统一 6px 间距，并按窗口宽度换行；卡片和输入框减少多余内边距，空提示和空预览不占位。文字对照在窄窗口上下排列，世界时钟和图片预览自适应宽度；多行输入顶端对齐，保留编辑与滚动空间。新增覆盖中英文、明暗主题和四种窗口宽度的实际 WPF 布局回归。

1.12.3 统一同组操作的宽高与间距：工具目录和固定操作使用相同列宽，并跟随搜索、滚动条与窗口宽度调整；快捷启动、文件收纳、OCR、音乐和计时操作改用等宽布局，长英文可换行。设置备份与诊断操作增加垂直间距。

1.12.2 统一为 iOS 风格的分组界面：浅灰与白色卡片、近黑与柔和灰色分层、蓝色强调、圆角控件和清晰的键盘焦点。消息、状态、全部工具和设置共用实时切换的主题，设置采用分组卡片与固定保存区域。收起音乐卡不再显示缺少进度或无法同步等说明；无可靠进度时隐藏进度轨，只保留歌曲、封面与播放状态，原因和完整歌词仍可在展开后的媒体面板查看。
