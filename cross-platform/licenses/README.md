# Bundled third-party notices

License text is retained verbatim. Byte-identical notices shipped by multiple
SkiaSharp and HarfBuzzSharp packages are included once under the shared names
below; this applies to their managed packages and Linux/macOS native assets.

| Component | License / notices |
| --- | --- |
| Avalonia 12.1.4 | `Avalonia-MIT.txt` |
| Inter font | `Inter-OFL.txt` |
| Tmds.DBus.Protocol 0.94.1 | `Tmds.DBus-MIT.txt` |
| MicroCom.Runtime 0.11.6 | `MicroCom-MIT.txt` |
| SkiaSharp 3.119.4 / HarfBuzzSharp 8.3.1.3 and native assets | `SkiaSharp-HarfBuzzSharp-MIT.txt`, `SkiaSharp-HarfBuzzSharp-ThirdPartyNotices.txt` |
| .NET runtime and bundled components | `DotNet-MIT.txt`, `DotNet-ThirdPartyNotices.txt` |
| QR Code Generator | `QR-MIT.txt` |

The QR algorithm is shared with the Windows application; the legacy bitmap
exporter is excluded from the modern .NET target. `upstream-sources.json`
records the official sources used for the separately fetched license files.
These third-party terms do not assign a license to the rest of Side Island.
